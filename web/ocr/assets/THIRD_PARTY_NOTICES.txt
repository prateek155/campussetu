Bundled OCR assets

- Tesseract.js 5.1.1 (Apache-2.0): https://github.com/naptha/tesseract.js
- Tesseract.js-core 5.1.1 (Apache-2.0): https://github.com/naptha/tesseract.js-core
- English trained data package @tesseract.js-data/eng 1.0.0 (MIT): https://github.com/naptha/tessdata

The runtime, WebAssembly core, and English language data are served from this
folder so the web app does not load OCR code or models from a third-party CDN.

The bundled JavaScript CDN fallback URLs are replaced with local-required fail-closed sentinels; this app supplies explicit local worker, core, and language paths.
